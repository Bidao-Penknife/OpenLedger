# ADR-016：统计快照、文件预览与原子报告

状态：已采纳，阶段 6。数据库版本继续为 1，不改动已应用的 `0001.sql`。

统计组件从同一 SQLite 只读快照构建不可变 `ReportData`。收支、月份、分类、排行、前期比较、筛选名称和修改日志版本共享该快照；界面和 PDF/PNG 直接消费 DTO，不在绘图时重新查库。资金累计使用 Python 整数；只将归一化比例转为绘图坐标。

收入只计有效收入交易；毛支出只计有效支出；退款按实际到账日期和到账账户计算，账本与分类继承原支出。净支出 = 毛支出 − 退款，结余 = 收入 − 净支出。转账、期初和余额校准不计收支。分类占比采用毛支出，避免退款造成负数饼图。没有收入时结余率不可定义；不将其显示为 0%。前期比较使用紧邻、天数相同的日期区间，界面标出两段日期。

桌面图表用 Qt Widgets / QPainter，报告用 QtGui 的 QPdfWriter。中文字体由系统选择并由 Qt 嵌入报告，不分发系统字体原文件；不引入 QtPdf、QML 或另一套报告运行库。PDF 支持分页，PNG 达到尺寸上限时拒绝输出并提示使用 PDF。

CSV 和 XLSX 由 `ExchangeService` 读取、预览和导出。XLSX 使用锁定的 openpyxl 与 defusedxml，限制 ZIP 成员、解压体积和压缩比，不计算公式，不保留外部链接。限制单文件 20 MiB、10,000 数据行、80 列和 8,192 字符单元格。CSV 使用明确选择的 UTF-8 或 GB18030 编码，只探测分隔符，固定双引号引用规则。

列映射及目的资料生成规范 JSON 和 SHA256。预览保存原文件摘要、行号、事务 UUID、错误与重复提示、意图摘要。确认时重新校验原文件和预览摘要，资金服务在写锁内重新校验全部约束。默认值只用于该字段未提供的行；显式未知引用及 ID/名称冲突拒绝导入，防止记入错误账户。跨库源 ID 未命中时允许按唯一名称匹配目的资料，需先创建资料。

`import.commit.v1` 和 `import.revert.v1` 复用既有资金事务、审计与幂等回执。提交任一行失败整批回滚。精确导入身份在删除及撤销后继续保留；模糊重复只提示，不擅自合并。撤销要求所有批次成员仍有效且版本 1，批次外有效退款阻止撤销；内部退款先撤销，不能单独恢复已撤销批次成员。

普通导入支持收入、支出、转账、支出退款。CSV/XLSX 导出同时保留期初和校准供查看，但不把它们作为可重放的普通交易：它们依赖账户切点和校准时的余额。完整数据库、审计、实体与附件恢复继续使用 `.olbackup`，文件交换不替代完整备份。

OpenLedger CSV v1 对数据文本添加一个前导单引号，并用 `text_escape=apostrophe-v1` 声明；本程序重导入时精确剥离一次，保持原有单引号和危险公式文本可逆。XLSX 写为显式字符串单元格，金额使用整数分字符串，避免 Excel 数字精度和公式解释。导出从一次读快照获得全部有效交易，默认不含已删除记录。

查询及文件 IO 使用后台任务，Qt 信号在 GUI 线程交付结果；代次编号丢弃过期预览。取消为协作式，已经确认的资金提交不被文件任务取消。导出在目标目录创建临时文件，关闭绘制和工作簿句柄，刷新并同步后原子替换；失败和取消保留原文件。
