# 统计、导入与导出

在「统计分析」选择起止日期（两端都包含），以及账本、账户、分类和标签，点击刷新生成报告。归档资料仍可筛选历史记录；多个标签的服务接口按任一标签匹配，桌面目前为单选。日期跨度最多 120 个月。

页面展示收入、毛支出、退款、净支出、结余和结余率。退款按实际到账月份计算，并继承原支出的分类与账本。转账、期初和余额校准不计入收支；总资产仍由账户有效流水计算。没有收入时结余率显示不可定义。前期比较使用紧邻的等长日期区间，请核对页面标出的日期。

月度趋势显示收入与净支出；分类占比按毛支出计算，避免退款导致负占比；消费排行可以选择商户、对象或分类，按金额或笔数排序。点击分类图表可查看该分类交易，保留日期和其他筛选。图表支持浅色、深色主题和键盘分类选择。

PDF 和 PNG 使用当前已生成的报告，包括筛选名称、统计口径、数据版本及生成时间。更改筛选后需要先刷新，才能导出新报告。PDF 支持多页 A4；PNG 数据太多时会提示改用 PDF，避免截断统计。导出不包含个人财务建议。

## 导入 CSV / Excel

1. 先在「账户与管理」创建目的账户并填写起算日期和期初余额，同时创建需要的账本、分类、标签及支付方式。
2. 在「导入与导出」选择 `.csv` 或 `.xlsx`；CSV 默认 UTF-8，也可选择 GB18030，Excel 可选择工作表。不支持旧 `.xls` 或含宏的 `.xlsm`。
3. 核对「列映射」。常见中文标题会自动识别；金额可以提供元字符串（最多两位小数），或整数分列。两种都提供时采用整数分列。日期使用 `YYYY-MM-DD`，Excel 日期单元格也可读取。
4. 核对「目标资料」。未提供的账本、账户或分类可使用明确选定的默认值。行内已有 ID 优先，其次唯一同名资料；未知显式名称和 ID/名称冲突显示错误。需要强制使用某个目的账户时，取消账户名称与 ID 列的映射，再明确选定默认账户。
5. 点击「重新读取并生成预览」。预览不会写数据库；含错误及精确重复的行不能勾选。疑似重复默认不勾选，核对后可手工勾选。可导出错误明细修正源文件。
6. 勾选有效行并「确认导入勾选行」，核对确认对话框。所有勾选行共同提交，任一资金约束失败整批回滚，预览保留供重试。原文件或映射改变后必须重新生成预览。

导入支持收入、支出、转账和支出退款。转账需两侧账户；退款需原支出的 `original_transaction_id`，可以引用库中原支出，或同一文件的导出交易 ID。勾选退款时，也须勾选其尚未入库的原支出。未知标签需先创建，不会静默丢弃。

外部订单去重需同时提供 `external_source`（来源名称）和 `external_transaction_id`（交易号）；交易号可为普通字符串，无须 UUID。只有订单号、没有来源时会显示错误。已导出的 OpenLedger 文件可以直接识别原交易 ID。相同文件／映射／行号，以及同来源／交易号，在删除和批次撤销后仍会阻止再次导入。

限制：每个文件最多 20 MiB、10,000 数据行、80 列；单元格最多 8,192 字符。XLSX 公式行拒绝导入，外部链接不加载；文件解压体积也有限制。Excel 数值金额若已经被 Excel 舍入，本程序无法恢复原值；推荐提供文本金额。文件读写和报告生成可取消，已经确认的资金事务会完整完成。

## 撤销与导出

选择「导入批次历史」中的已提交批次，点击撤销并确认。仅当所有成员未编辑、未删除且没有批次外有效退款时允许整批撤销。冲突时整个操作拒绝，已有记录保持原状。撤销身份仍保留，撤销后的成员不能逐笔恢复；需要保留时应在撤销前检查。

「导出全部有效交易」输出一次数据库快照中的 CSV 或 XLSX。金额以整数分十进制字符串保存，保留日期精度、时区、原文、标签、支付方式、转账两侧和退款关联。文件也包含期初、余额校准供查看，它们不会作为普通交易导入；完整恢复使用[备份与恢复](../development/backup-recovery.md)。普通交换不包含所有实体、审计、附件和桌面设置。

CSV v1 使用 UTF-8 BOM。为防止表格软件把备注等解释为公式，数据字段带一个单引号，声明为 `apostrophe-v1`；本程序重导入会精确还原。普通第三方 CSV 的单引号不会自动剥离。XLSX 直接将数据写为字符串单元格，不执行公式。导出成功后才替换目标文件，取消或失败会保留原文件。
