# 使用指南：本地财务与可选智能记账

本指南对应 `1.0.0rc1`，包含记账、账户、统计与交换、桌面快捷入口和可选 AI。安装、升级与卸载见[安装指南](installing.md)，当前状态见[阶段 8 记录](../development/phase8-validation.md)，桌面与可选联网流程见[系统与 AI 指南](system-and-ai.md)。历史记录保留各自快照结果；使用说明不代替实测记录。

## 源码启动

在 Windows x64 上准备 Python 3.12 与 uv，在仓库根目录运行：

```powershell
uv sync --locked --group dev --group build
uv run --locked python main.py
```

模块入口行为相同：

```powershell
uv run --locked python -m openledger
```

已激活 `.venv` 时可使用 `python main.py`。首次同步需要下载依赖；应用正常启动不联网，不需要 AI 服务或云端账号。AI 与版本检查均要求用户配置并手动发起。

## 首次使用

启动会创建或验证本地数据库，建立“我的账本”、常用分类和支付渠道；不会添加示例交易、账户或猜测余额。

1. 打开“设置”，核对记账时区。初始值为 `Asia/Shanghai`；需要其他时区时选择有效的 IANA 名称并点击“应用设置”。
2. 打开“账户与管理”，资料类型选择“账户”，点击“新建”。填写名称、账户类型、开始记账日期和该日期的期初余额。余额为零时明确填写 `0.00`。
3. 返回“总览与记账”，输入“咖啡 25元”，按 Enter 或点击“解析草稿”。核对金额、日期、资金账户、账本和分类，补齐缺少的信息后点击“确认保存”。
4. 在“交易记录”查看结果。也可以选择“手工录入”，直接填写确认表单。

支付方式和资金账户分别选择。“微信支付”表示渠道；实际扣款账户只有通过明确的渠道账户映射或手工选择才能确定。默认账户会标为默认建议，仍需核对。完整操作和资金口径见[记账指南](bookkeeping.md)。

## 窗口与退出

左侧导航包括“总览与记账”“交易记录”“账户与管理”“设置”“统计分析”和“导入与导出”。首页汇总总资产、本月收入及本月净支出；设置页同时显示运行环境、数据库版本和日志模式。

自然语言输入框获得焦点时，Enter 用于解析，Ctrl+Enter 用于确认保存，Shift+Enter 换行。这些操作会检查输入法组合输入状态，选词时不会触发解析或保存。保存按钮同样要求有效草稿，并在正在保存时暂停其他提交。

默认关闭主窗口会隐藏到可用系统托盘，设置中可修改该行为。侧栏“退出”、Ctrl+Q 或托盘“退出 OpenLedger”明确退出；已开始的资金提交完成后再关闭。托盘不可用时正常关闭。未保存草稿在本次隐藏期间保留，退出后不保留。默认 Ctrl+Alt+L 打开快速窗口；Enter 解析、Ctrl+Enter 核对后保存，Esc 隐藏。重复启动同一数据目录会激活已有窗口；`--quick` 激活快速窗口。

## 查看统计与交换文件

在“统计分析”选择日期与账本、账户、分类、标签，刷新后查看收入、毛支出、退款、净支出、结余和图表。退款按到账日期计算，转账、期初和余额校准不计收支；没有收入时结余率不可定义。消费排行可按商户、对象或分类，选择金额或笔数；点击分类图表查看相关交易。

PDF/PNG 导出使用当前已生成的报告，保留筛选条件、数据版本和生成时间。修改筛选后先刷新，再导出新报告。PDF 可分页，PNG 超过尺寸上限时提示改用 PDF，避免截断数据。

在“导入与导出”选择 CSV 或 XLSX，核对编码/工作表、列映射和目标资料，再生成预览。实际账户、账本和分类以行内字段或明确默认值为准，需要逐行核对；错误及精确重复不能勾选，疑似重复默认不勾选。确认后所选行整体入账，任一约束失败整批回滚并保留预览。撤销批次还要求成员未改动且没有批次外退款，不能用撤销绕过资金规则。

文件读取、预览和导出可取消；取消尚未提交的确认准备不会入账，已经确认的资金事务完整完成。普通导入支持收入、支出、转账和支出退款，不支持旧 `.xls`、宏 `.xlsm` 或公式行。完整操作、格式与文件限制见[统计与数据交换指南](analysis-and-exchange.md)。

## 安装与便携运行

可运行当前用户安装 exe，或将便携 ZIP 完整解压后运行 `OpenLedger.exe`。保留 `_internal`、资源及许可证材料；移动便携程序时移动整个目录。候选制品未签名，稳定版与干净系统验收状态见阶段 8 记录。

当前仓库没有正式下载地址。以本阶段交付说明提供的实际制品为准，勿从同名或未经确认的仓库获取程序。

## 数据、设置与日志

默认目录为 `%LOCALAPPDATA%\OpenLedger`，与程序安装位置分离。当前创建以下目录：

```text
OpenLedger/
├── database/
│   └── openledger.sqlite3
├── attachments/   # 后续附件目录
├── backups/
├── logs/
│   └── startup.log
├── settings.json         # 桌面偏好、语言与记账时区
├── ai-settings.json      # 自行保存后的非敏感 AI 配置
└── update-settings.json  # 手动检查时保存的 GitHub 仓库
```

数据库保存账目、流水、默认账本/账户、审计和命令回执。桌面偏好与时区保存在原子替换的 `settings.json`，AI 密钥只保存在 Windows 凭据管理器；配置与凭据不进入资金备份。恢复新目录后重新配置。设置缺失或无效时采用浅色、简体中文和 `Asia/Shanghai`。系统主题即时生效，英语选择下次启动生效，修改时区使未保存自然语言草稿失效；历史交易保留原时区。

启动日志使用 UTF-8，并限制大小与轮转数量。分享日志前检查是否包含个人路径等信息。当前没有自动上传日志或崩溃报告。

源码启动可用 `--data-dir` 指定绝对路径：

```powershell
uv run --locked python main.py --data-dir D:\OpenLedgerData
```

冻结程序可使用相同参数：

```powershell
.\OpenLedger.exe --data-dir D:\OpenLedgerData
```

相对路径会被拒绝，避免工作目录变化导致数据位置漂移。若目录不可写，选择当前用户可写的绝对路径后重试；不需要将程序默认以管理员身份运行。

当前没有数据库备份/恢复按钮，但提供维护命令：

```powershell
uv run --locked python main.py --data-dir D:\OpenLedgerData --backup D:\MyBackups\ledger.olbackup
uv run --locked python main.py --restore D:\MyBackups\ledger.olbackup --restore-to D:\OpenLedgerRestored
```

父目录必须已存在，备份文件不能覆盖已有文件，恢复只能写入新目录或空目录。关闭应用后再用 `--data-dir D:\OpenLedgerRestored` 启动；原目录保留。备份包含完整账目、审计、回执和引用的附件，未加密，不包含桌面设置或未保存草稿。格式与验证说明见[备份恢复指南](../development/backup-recovery.md)。CSV/XLSX 导出供查看和数据交换，不包含全部实体、审计及附件，不能代替完整备份。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| `No module named openledger` | 在项目根目录执行锁定依赖同步，并通过 `uv run --locked` 或已激活的 `.venv` 启动 |
| 提示数据目录不合法或不可写 | 使用绝对 `--data-dir`，确认该位置当前用户有写权限 |
| 冻结程序缺少 DLL 或 Qt 平台插件 | 重新解压完整目录，核对制品校验和，不要单独复制 exe |
| 窗口提示 WAL 版本未满足 | 当前采用 DELETE 回滚日志；无需强行启用 WAL，参见数据库运行策略 |
| 没有账户，无法确认保存 | 在“账户与管理”新建账户，并明确填写期初余额和起算日期 |
| 已识别微信支付，仍需选择资金账户 | 渠道不等于账户；手工选择，或在支付渠道资料中配置“建议付款账户” |
| 解析提示歧义或多个金额 | 修改原文，逐笔选择明确的候选，或切换手工录入；程序不会自动合并或保存 |
| 保存提示日期不合法 | 检查未来日期、账户起算日期、原支出日期和当前记账时区；原输入保留 |
| 编辑提示版本冲突 | 刷新列表并重新打开记录，核对最新内容后再提交 |
| 图表或导出与改过的筛选不一致 | 修改筛选后点击刷新；导出使用当前已生成的报告快照 |
| 导入提示精确重复或缺少原支出 | 核对来源/交易号与源文件行身份；退款需已有原支出，或同时勾选其尚未入库的源行 |
| 撤销批次失败 | 核对成员是否已编辑/删除或关联批次外退款；拒绝时原数据保持不变 |
| PNG 提示数据过多 | 缩小统计范围或改用完整分页 PDF |
| 希望启用 AI、托盘或全局快捷键 | 在“设置”配置；AI 默认关闭，需自行填写服务并明确点击解析；桌面入口与发送范围见[系统与 AI 指南](system-and-ai.md) |

问题报告附上版本、Windows 版本、入口方式和合成复现，不提交真实账单或凭据。贡献与安全报告规则见 [贡献指南](../../CONTRIBUTING.md) 和 [安全说明](../../SECURITY.md)。
