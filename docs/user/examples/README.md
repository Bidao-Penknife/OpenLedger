# 合成导入样例

所有姓名、金额和事件都是测试数据。先创建备份，再预览并明确勾选有效行。

- basic-cny.csv / basic-cny.xlsx：选择 CNY 默认账户、账本、收入分类与支出分类；不能重复导入同样文件。
- fx-transfer.csv / fx-transfer.xlsx：先新建账户“合成日元”（JPY，期初 5000）和“合成现金”（CNY，期初 1000），映射两个账户名称、币种、转入金额与转入币种。1000 JPY 转出，实际 48 CNY 到账，余额应为 4000 JPY 和 1048 CNY。
- 样例日期为 2026-10-06，账户起算日期不得晚于它；若修改日期，不要填未来日期。
- 报告需要估值时，另设合成手动汇率 1 JPY = 0.05 CNY（日期不晚于记录日）。实际到账 48 CNY 不会被手动估值改写。
- 公式与错误行不能入账；批次撤销在后续修改/退款依赖时可能被拒绝，请按提示处理。

软件原生导出使用最小单位整数字符串；本样例“金额”“转入金额”使用主单位十进制文本。
