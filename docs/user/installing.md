# 安装、升级与卸载

当前版本为 `1.0.0rc1`，Windows x64 发行候选。安装 exe 和便携 ZIP 未签名，实际验收范围见[阶段 8 记录](../development/phase8-validation.md)。

## 安装

1. 核对候选版下载文件的 SHA256 与同次发行清单。
2. 运行 `OpenLedger-1.0.0rc1-windows-x64-setup.exe`，默认当前用户安装，无需管理员权限。
3. 保持程序与账目分开。程序默认在 `%LOCALAPPDATA%\Programs\OpenLedger`；账目默认在 `%LOCALAPPDATA%\OpenLedger`。
4. 从开始菜单或安装完成页打开应用。桌面快捷方式可选，默认不勾选。
5. 首次使用按[启动指南](getting-started.md)创建账户，并明确起算日期与期初余额。

安装器支持简体中文与 English，应用语言在自己的设置中选择。安装不建立开机启动、文件关联或 AI 凭据。不需要额外安装 Python；当前机器上的运行验证与干净系统认证在记录中分别列出。

便携方式完整解压 ZIP 后运行 `OpenLedger\OpenLedger.exe`。保留 `_internal`、翻译、迁移和许可证目录。便携指程序文件可移动，默认账目位置仍是用户 LocalAppData；需要其他账目位置时使用绝对 `--data-dir`。

## 升级与回退

升级前先验证财务备份，再使用主窗口或托盘“退出”菜单退出所有实例。直接关闭主窗口可能只隐藏到托盘。运行新安装程序并使用原安装目录，固定 AppId 会更新当前用户安装项。遇到活跃应用时，安装器拒绝操作，不强制结束进程、不安排重启。

同版本安装可修复已发行文件。较低版本不能覆盖较高版本。程序目录中的未知文件不会由安装器递归清空；不要在程序目录存放账目。今后若版本移除运行库，维护者须验证旧文件残留是否影响插件加载；不以删除未知文件简化升级。

回退使用独立程序目录和该版本支持的已验证备份，恢复到新的账目目录，再用 `--data-dir` 启动旧程序。恢复不覆盖原账本；不要让旧程序访问它不支持的未来数据库版本。备份和恢复命令见[备份指南](../development/backup-recovery.md)。

## 卸载

先退出所有实例，再从 Windows“已安装的应用”卸载 OpenLedger。卸载移除安装器记录的程序文件、快捷方式与当前用户卸载项，保留账目、备份、偏好、未登记的程序目录文件和 AI 凭据。

重新安装后仍可使用原账目。财务备份不包含桌面/AI 配置或密钥。移动账目目录、换服务地址或换电脑后，按[系统与 AI 指南](system-and-ai.md)重新核对配置。删除 AI 密钥使用应用设置中的明确删除按钮；卸载器不枚举或删除其他服务凭据。

## 核对校验值

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\OpenLedger-1.0.0rc1-windows-x64-setup.exe
```

校验值用于确认文件与清单一致，不代替发布者身份验证或代码签名。正式版发布时间、托管仓库与签名方式由维护者确认，当前不提供虚构 Release 链接。
