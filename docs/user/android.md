# Android 手机使用指南

Android 0.3.0-beta1 新增通知、离线中文 OCR、语音及多币种。完整步骤、实际截图、样例和排错请先阅读[新版完整手册](complete-manual.md)；下文保留已有日常功能的简明操作。

本指南对应 Android `0.2.0-beta1-preview`。下载来源为[项目 Release](https://github.com/Bidao-Penknife/OpenLedger/releases/tag/android-v0.2.0-beta1)。旧公开 alpha 可以使用同签名 APK 覆盖安装；请先备份，不要先卸载或清除应用数据。自行构建和 CI APK 使用各自调试密钥，不能假设它们可覆盖公开测试包。

## 第一次记账

创建账户，填写真实的起始余额与起算日期。现金、银行卡、微信、支付宝和自定义账户都使用独立余额。默认账本为“我的账本”，可另建旅行、家庭或学习账本。

在“记下一笔”输入“昨天晚上和朋友吃火锅128元，微信支付”，点击“解析并核对”。本地规则给出草稿，核对金额、账户、分类、日期/时段、对象、备注与标签后确认保存。支付渠道可以显式绑定资金账户，没有绑定时需要选择账户。多笔建议逐笔确认；解析不会直接扣款。无法确定的字段可以手动填写。

## 流水与账户

“流水”支持搜索、分页与组合筛选。点一笔查看详情，可编辑、删除或恢复。删除为软删除，勾选“显示已删除”可找回。原支出存在有效退款时，系统会阻止破坏退款关系的修改或删除；先处理关联退款。

“账户资产”提供转账和资料管理。转账只改变两个账户，不算收入或消费。退款从原支出详情进入，可退到不同账户，金额不能超过未退款部分。期初修改与余额校准分别用于纠正起始数据和核对当前实际余额；校准必须填写原因，校准金额不会当作收入/支出。

账本、账户、分类、标签和支付渠道采用归档，保留历史记录。归档当前默认账本/账户需要选择替代默认项。历史记录可继续引用原资料，新增交易需要有效资料。

## 图片与备份

在交易详情选择“添加收据图片”，通过系统选择器选取 PNG/JPEG/WebP，查看预览后确认。单张不超过 20 MB、5000 万像素。删除图片保留可恢复的历史文件，不改变金额；附件随完整备份迁移。

在“设置”选择“导出完整备份”，把 `.olbackup` 保存到自己选择的文件夹。备份包含账目、资料、审计记录和数据库引用的图片，不包含 AI 密钥。CSV/XLSX 用于交换记录，不能替代完整备份。

恢复需要选择完整备份并再次确认。应用验证备份并恢复到新数据目录，成功后才切换，原目录保留。在“切换保留的数据”可返回原账本；恢复是整份数据切换，不是合并两端修改。未完成的资金确认会阻止切换。

手机与 Windows 共用备份格式，两个应用仍独立保存。操作前备份各自数据，恢复不会自动同步另一台设备。共享 Schema v1 中的附件会完整保留，Windows 当前没有附件查看入口。

## 统计与文件交换

“统计分析”按日期、账本、账户、分类和标签生成收入/净支出趋势、分类占比、消费排行与前期比较。分类占比使用退款前的消费，净支出按退款入账日期抵扣；报表会说明筛选和统计口径。转账、期初和校准不作为消费。可将同一报告导出为 PDF 或 PNG；较长报告使用多页 PDF。

“设置”可导入 CSV 和 XLSX。CSV 可选 UTF-8 或 GB18030；Excel 可选工作表。映射日期、金额、类型等列，填写缺失的默认资料后预览。错误行不能勾选，疑似重复需要自己核对；明确勾选后再次确认，整批成功或回滚。导入历史支持批次撤销，已修改的成员或存在依赖的批次会被阻止撤销。最大 20 MiB、10000 数据行，不支持 `.xls`、`.xlsm`、公式计算或外部链接。

CSV/XLSX 导出包含当前数据目录的有效交易、精确金额及可交换字段。下载文件由系统选择器保存到明确位置。导出表格中的危险文本按共享安全规则编码。

## 外观、AI 和快速入口

“设置”可选择浅色、深色或跟随系统、中文/英语和 IANA 时区。时区影响今天及新记录，历史交易保留其原时区；界面翻译不改写已有账本名、分类名和备注。

AI 默认关闭，需自行填写兼容 API 的 HTTPS 地址、模型和密钥。密钥由 Android Keystore 加密并按服务/数据目录隔离；恢复到新目录后重新配置。只有明确点击“AI 解析”并确认才发送当前文本和必要的资料选项，不发送完整账目历史或账户余额。响应仍是待核对草稿，不会自动入账。备份不保存密钥，应用清除数据后不能从财务备份恢复密钥。

可添加桌面快捷方式，或在系统快捷设置中加入 OpenLedger 磁贴；它们打开同一确认记账页面。是否允许固定快捷方式由启动器决定。检查更新只访问本项目公开 Release，比较 APK 版本并提示打开发布页，不自动下载和安装。

应用没有读取支付通知、后台自动扣账、云同步服务器、OCR、语音录入或插件市场。版本仍为测试版；当前实测为本机 Android 15 / x86_64 模拟器，ARM64 真机和最低系统运行见后续验收计划。
