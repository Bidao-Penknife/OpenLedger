# 桌面入口、外观与可选 AI

本指南介绍阶段 7 的 Windows 功能。基础资金规则和 CSV/XLSX 交换方式分别见[记账指南](bookkeeping.md)与[统计及数据交换指南](analysis-and-exchange.md)。技术边界见 [ADR-017](../adr/017-desktop-and-optional-services.md)。功能说明不代表已在真实 AI 服务、远端 GitHub CI 或干净 Windows 虚拟机上完成验收；实际验证结果以本阶段交付记录为准。

## 托盘与退出

正常桌面启动默认显示系统托盘图标。右键菜单提供“打开主窗口”“快速记账”和“退出 OpenLedger”；双击图标恢复主窗口。在“设置”中可以关闭托盘、关闭窗口隐藏行为，或关闭全局快捷键，点击“应用设置”生效。

启用“关闭主窗口时隐藏到托盘”且系统托盘可用时，主窗口右上角关闭按钮只隐藏窗口。托盘不可用或已禁用时，关闭主窗口正常退出。“退出”、托盘中的“退出 OpenLedger”和主窗口 Ctrl+Q 明确退出应用。已经开始的资金保存会完成后再退出，避免保存中释放数据库或重复提交。

快速窗口的关闭按钮与 Esc 只收起快速窗口，本次运行中的草稿保留。彻底退出应用后，未保存草稿不保留。退出前核对是否还有未确认记录。

## 全局快捷键与快速记账

默认快捷键为 `Ctrl+Alt+L`，正常桌面启动时才向 Windows 注册。在其他应用中按下快捷键可以打开已有的快速窗口；反复触发复用同一个窗口，不建立多个草稿或写入器。

1. 输入一笔记录，例如“咖啡 25元”。
2. 按 Enter 或点击“解析草稿”，生成本地规则建议。解析不会改变余额。
3. 核对金额、日期、账户、账本、分类与支付方式，补齐缺少信息；也可明确选择“手工填写”。
4. 点击“确认保存”或在输入框中按 Ctrl+Enter。成功后清理本窗口草稿，可以继续下一笔；失败保留原文、字段和交易标识供重试。

输入框 Shift+Enter 换行。组合输入期间不触发解析或确认，避免中文选词按键误记账。表单编辑框中的 Enter 不会隐式点击保存。快速窗口要求每次输入一笔；多笔或有歧义时拆分输入，或回主窗口逐笔选择候选。未来日期不能默认作为今天保存。主窗口与快速窗口各自保留草稿，使用同一个异步资金写入边界；任一保存进行时暂停其他提交。

快捷键可使用 Ctrl、Alt、Shift 与一个英文字母、数字或 F1–F24，至少包含 Ctrl 或 Alt，例如 `Ctrl+Shift+F9`。不支持单键、重复修饰键、Win 键或任意键名。若组合被其他软件占用，界面会提示 `HOTKEY_CONFLICT`；运行中换绑失败保留旧快捷键，托盘仍独立可用。设置可能保存了新组合，需要更换组合后再次应用；不要仅依据设置文字判断注册成功。

也可以使用命令行打开快速窗口：

```powershell
uv run --locked python main.py --data-dir D:\OpenLedgerData --quick
```

便携程序参数相同：

```powershell
.\OpenLedger.exe --data-dir D:\OpenLedgerData --quick
```

## 单实例与数据目录

同一解析后的绝对数据目录只允许一个正常应用实例。再次启动会请求既有实例显示主窗口；加 `--quick` 请求快速窗口。激活消息只包含窗口动作，不包含交易内容、金额或记账命令。既有实例暂时不能响应时，第二个进程退出并报失败，不会自行接管活跃实例的账本。

不同 `--data-dir` 可以分别运行，每个目录有自己的账目、设置与实例锁；全局快捷键仍受 Windows 冲突约束，需要配置不同组合。程序退出时释放实例锁；进程崩溃后，Qt 根据进程存活状态处理过期锁。不要在应用仍运行时手动删除 `.instance.lock`。

## 主题与语言

“设置”支持浅色、深色及跟随系统。跟随系统时，Qt 收到 Windows 外观变化后更新绘制主题；明确选择浅色或深色时保持人工选择。统计图和快速窗口跟随有效主题，PDF/PNG 导出使用当前报告绘制主题。

界面语言支持简体中文与 English。选择后应用设置，下一次启动生效；当前窗口不会重建并丢失草稿。英语界面不会改写已有分类、账户、备注或原文。本地自然语言规则仍以中文为主要输入，图表内部绘制文案、领域校验提示与报告文字仍可能保留中文，不能据此认为新增了英语记账语法或全部图表翻译。

## 自行配置 AI

默认 AI 关闭。本地解析始终可用，不需要 API 密钥，也不会在启动、打开设置、保存配置、按 Enter 或打开快速窗口时连接 AI。当前 AI 按钮位于主窗口，快速窗口采用本地规则。

在“设置”的“可选 AI 解析”中填写兼容服务的 API 基础地址、模型和密钥，阅读发送范围后勾选启用并保存。地址应为基础路径，例如以 `/v1` 结尾；不要填写完整 `/chat/completions` 路径。模型由服务提供者说明为准，不预设默认模型。远程服务需要 HTTPS；本机 HTTP 仅在明确允许时支持 `localhost` 或回环 IP 地址。当前适配器使用 Chat Completions 的 JSON mode，兼容服务需支持这一协议，不能保证所有标称“兼容”的服务都可直接使用。

回到主窗口输入文字，点击“AI 解析”才发起一次请求。发送内容为：

- 当前输入原文、参考日期、记账时区与人民币币种标记。
- 当前账本 ID。
- 可用账户、分类、支付方式的名称、ID 及类型元数据。

账户名称等也可能包含私人信息，请在启用前确认愿意发送到所配置的服务。账目历史、余额、附件、审计、整库数据和默认账户选择不在请求中。密钥只作为该服务请求的认证凭据使用；修改服务地址需为新服务配置相应密钥。

返回结果进入可编辑草稿，金额、日期、时间精度、ID、分类类型、原文范围等会经过本地校验。AI 不能直接保存、转账、退款、校准余额或调用资金命令。保存前仍需核对；明确确认后记录来源为 `ai_assisted`。修改原文、表单、时区或 AI 配置，取消请求，或重新选择本地/手工解析后，旧响应不能覆盖当前草稿。

连接错误、无效建议或取消后可继续本地解析，不会自动重试或自动切换服务。取消为协作式，已经阻塞的网络调用可能需要等到有限超时结束；应用退出会先释放工作任务。界面显示安全错误码，不展示服务响应正文或密钥。

## 密钥与配置文件

密钥保存到当前 Windows 用户的凭据管理器，不写入设置 JSON、资金数据库、CSV/XLSX、报告或财务备份。凭据目标按绝对数据目录和 API endpoint 分开，形如 `OpenLedger/AI/<哈希>`。同一目录、同一基础地址的不同模型共用该服务凭据；移动或恢复到另一个数据目录、换服务地址或换电脑后需要重新配置。

密钥输入框留空表示保留该服务已存密钥。“删除此服务的密钥”只删除当前基础地址对应的应用凭据，不清空其他服务或其他程序的凭据。Windows 凭据管理器不可用时提示失败，没有明文保存回退。

数据目录中的 `.instance.lock` 是运行锁；`settings.json` 保存桌面偏好，`ai-settings.json` 保存无密钥的 AI 配置，`update-settings.json` 保存公开发布仓库。财务备份不包含这些偏好、凭据或未保存草稿，恢复后重新核对配置。

## 手动检查更新

当前项目不预设真实发布仓库。在“设置”的“软件更新”填写你信任的公开 GitHub 所有者与仓库名，不填写完整网址、Token 或下载地址。点击“检查更新”时才保存选择，并匿名请求该仓库的最新稳定 Release；未配置时不会联网。

检查只提醒新稳定版本，忽略预发布版本，不自动下载或安装。另点“打开 Release 页面”才在浏览器打开已校验的发布页。仓库不存在、没有稳定 Release、限流、超时或网络异常时会提示；可以取消检查，稍后手动重试。此功能不说明本仓库已经发布到 GitHub。

## 当前发布范围

当前 `1.0.0rc1` 提供完整源码、Windows x64 便携包和当前用户安装程序，候选制品未签名。将 ZIP 完整解压后运行，保留 `_internal`、资源和许可证材料；安装版的程序与账目目录分开，升级与卸载流程见[安装指南](installing.md)。普通权限的本地安装生命周期验证已通过，无 Python 的独立 Windows 验收仍待执行，不能据此声明稳定发布。云端同步和插件市场尚未实现。
