日期：2026-10-02。版本：0.0.2.dev0。范围：OLG-009–014。

## 已完成

- 标准库 sqlite3 适配器、16 张表/27 个显式索引/2 个视图、带精确摘要的初始迁移、外键与 STRICT、数据库身份/版本/结构检查、写锁和只读快照。
- 整数分、Decimal 输入、UTC 毫秒和用户 IANA 时区校验；账户、账本、分类、标签、支付方式管理、默认切换、归档与乐观版本。

- 精确余额/总资产查询及 int64 边界；启动/备份/恢复检查 SQL 外键无法表达的资金关系。
- 一致 .olbackup 归档、附件校验、新目录恢复与恢复收据；不启动 Qt 的维护命令。
- 桌面启动接入数据库与默认 metadata，显示 schema 版本和日志模式；不生成示例交易或猜测账户余额。

## 实施选择及边界

阶段 2 的 SQLAlchemy/Alembic 规划修订为标准库显式事务与单分支线性迁移；理由见 [ADR-013](../adr/013-sqlite-migrations.md)。实际 Python UUID 接口用规范字符串，精确时间统一 UTC 毫秒，默认偏好落在资金事务内，恢复只写新目录；详见 [ADR-014](../adr/014-financial-command-boundary.md)。领域层不依赖 Qt/SQLite，展示层后续通过 LedgerPort 接入。

图形界面尚未开放录入、交易明细和资产管理交互，Python 资金服务已经实现；自然语言解析、分析、导入导出、AI、托盘、热键和更新在后续阶段。没有安装器、签名、干净虚拟机、Windows 10 或 ARM64 验收。备份未加密，审计不是防恶意篡改认证，在线原库覆盖恢复尚未开放。

远端 GitHub CI 尚未执行，仓库没有 remote、Release 或实际 GitHub Issues。Git 作者身份未配置，未替维护者设置身份或创建署名提交。原阶段 3 验收文件与制品保留，不把本阶段结果追写到历史记录。
