## 关键覆盖

- 真实旧发布源码生成的 Schema 1 合成夹具：迁移保持 CNY 历史金额、账户分录、UUID、审计、变更序号和回执；迁移前备份及旧完整备份恢复通过。
- JPY / USD / KWD / CLF 最小单位、精确有理数估值、半值舍入、缺报价提示、历史日期报价、实际双端换汇、重试、软删除 / 恢复、CSV/XLSX 往返和批次撤销。
- 通知更新只更新一条待确认草稿，独立事件保留；退款与付款分别校对；保存重试只扣款一次。实际系统 NotificationListener 接收经过显式授权的合成通知。
- APK 中 bundled Chinese 模型断网首次识别中文合成收据（原价 128、优惠 28、实付 100），原图展示 / 多候选选择 / 确认保存 / 原图完整备份恢复。多次 OCR 初始化已修复为每进程一次。
- 中文“三十五元”解析为 35.00 CNY；语音服务可用性、系统麦克风拒绝及可编辑文字回退界面验证。模拟器没有验证真实人声和手机中文识别服务。
- 原图待确认状态也随完整备份迁移；不合法确认整笔回滚；归档、退款关系、导入依赖与并发版本由同一财务事务检查。

## 实测边界

当前是同签名预发布 APK；声明 ARM64 / x86_64 和 API 24 起不等于相应实体设备认证。真机、最低 Android 7、真实支付应用格式、真实语音服务、输入法与低存储等后续覆盖见 [#6](https://github.com/Bidao-Penknife/OpenLedger/issues/6)。通知来源的事件标识变化可能产生两条待确认，需要人工校对。

OCR 图片和文字在本机处理，但第三方 SDK 可发送设备 / 应用 / 性能诊断，首次使用前披露且启动不初始化；普通系统语音可能联网，调用前确认。AI 默认关闭，未用真实用户凭据调用商业服务。云同步服务器和插件市场没有实现，完整备份迁移不是自动合并。

真实账本、完整财务备份、私钥和认证令牌不在公开源码或证据 ZIP 中。截图、收据和数据库测试均使用明确标识的合成资料。
