# 开发路线图与本地任务

OpenLedger 按“需求与设计 → 小范围实施 → 实际验证 → 阶段交付”推进。`OLG-xxx` 是计划 ID，尚未映射到 GitHub Issues；当前版本为 `1.0.0rc1`，没有已发布稳定版本。

## 完成规则

每个任务需要明确行为、验证方法与失败路径，资金任务还需验证不变量和原子性。阶段交付记录已完成内容、实际测试、制品、限制和下一阶段范围，再等待维护者或用户指令。

完整原始计划保留在 `docs/architecture/phase2/` 中。发生设计调整时，通过 ADR 与变更说明记录现行决策，不静默修改历史验收结果。
