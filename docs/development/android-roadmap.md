# OpenLedger Android 功能与路线

更新日期：2026-10-06。本期 Android 为 `0.2.0-beta1-preview`，Windows 仍为 `1.0.0rc1`。维护者要求连续按顺序补齐 A–D，功能已经接入手机；稳定版的正式签名、真机和最低系统验收单独记录。

## 功能状态

| 能力 | 本期手机入口与行为 |
| --- | --- |
| 自然语言/手动收支 | 本地中文规则生成草稿，逐笔核对金额、账户、分类、日期和来源后保存 |
| 多账本/账户/资料 | 默认“我的账本”；现金、银行卡、微信、支付宝、自定义；分类、标签、支付渠道和默认绑定，可编辑/归档 |
| 交易维护与资金操作 | 详情、版本校验编辑、软删除/恢复、转账、关联退款、期初修改及有原因的余额校准 |
| 查询 | 搜索分页；账本、账户、分类、标签、类型、日期与已删除状态组合筛选 |
| 完整备份/恢复 | 系统文件选择器；共享桌面 `.olbackup`；新目录恢复、失败保留、原数据切回；确认前持久保存恢复来源 |
| 图片附件 | 系统选取 PNG/JPEG/WebP，原生预览，审计删除/恢复，完整备份携带引用文件 |
| 统计 | 月度收入/净支出趋势、分类占比、排行、等长前期比较；金额保持整数分/十进制文本 |
| CSV/Excel | UTF-8/GB18030、XLSX 工作表/映射、只读预览、重复提示、明确选择、原子批次、可检查的批次撤销及导出 |
| PDF/PNG | 同一精确统计快照；Android 原生绘图、多页 PDF、完整 PNG 与安全尺寸限制 |
| AI | 默认关闭；自配兼容 HTTPS API 和模型；Keystore 加密密钥、独立 JNI 参数、建议再次确认 |
| 设置 | 中文/英语、浅色/深色/系统主题、IANA 时区；历史交易保留原时区 |
| 快速入口/更新 | 固定快捷方式、系统磁贴；手动检查本项目 APK Release，只提醒和打开网页 |
| 扩展与同步 | AI/分析/导入/主题契约和同步 DTO/端口预留；没有插件市场或实际云同步服务器 |

手机与桌面仍分别本地保存。移动完整备份可以传递账本，恢复不是自动合并或同步。应用不读取支付通知、不执行后台自动扣款、OCR 或语音识别。第一版只支持 CNY。

## 已验证范围与限制

本机 Android 15 / API 35 / x86_64 合成模拟器验证真实 APK。所有 UI 夹具显式授权并先恢复到独立测试目录，结束后切回原目录，避免用跳过的旧 UI 夹具代替通过。升级验证使用原公开 alpha 和相同签名的 beta；强制结束后冷启动核对资产与支出，原始合成数据库摘要保持一致。具体测试数量、构建、Lint、APK 摘要与发布状态见[阶段 11 验证](phase11-validation.md)。

APK 声明最低 API 24、支持 ARM64/x86_64；静态兼容性检查通过不等于 Android 7 设备运行。当前保持调试签名与预览包名，不能称为正式真机认证。自行构建和 CI APK 的调试密钥可能不同，覆盖安装应使用同一个公开发布来源。卸载/清除应用数据前导出完整备份，备份不保存 AI 密钥。

未使用真实用户 AI 凭据调用商业服务；网络协议、禁用状态、密钥缺失、建议校验和敏感字段不外传通过受控传输测试，Keystore 和 CA 在 APK 内验证。实际云传输按照原需求只预留接口，后续需要独立设计身份、冲突与合并策略。
